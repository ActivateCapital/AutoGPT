# CreAI Agent Skills Pack

Five business skills for Claude Code, Cursor, and every SKILL.md-compatible agent.
Drop them in, and the AI agent you already pay for becomes your lead qualifier, inbox
triager, content repurposer, meeting secretary, and weekly-review analyst.

**Why skills instead of scripts:** zero setup friction. No Python, no API key, no
terminal — if you use Claude Code (or any of the 20+ agents that read `SKILL.md`), you
install these by copying a folder. The skill triggers automatically when your work
matches it.

## The five skills

| Skill | What it does |
|---|---|
| `creai-lead-qualifier` | Scores and ranks any lead list against your ICP rubric, with written reasons per lead |
| `creai-inbox-triage` | Sorts pasted/exported email into act-now → archive, drafts the replies worth sending |
| `creai-content-repurposer` | One post or transcript → X thread, LinkedIn post, newsletter section, YouTube description, in your voice |
| `creai-meeting-actions` | Meeting transcript → decisions, owned action items with deadlines, follow-up email draft |
| `creai-weekly-review` | Your week's raw notes/metrics → honest review: wins, misses, numbers, next week's top 3 |

Each skill ships with an editable reference file (your rubric, your context, your
voice) — the same plain-English customization layer as our full kits, minus all the
infrastructure.

**Free sample:** `creai-meeting-actions` is available as a free download on the
storefront (no email required) — it's the try-before-you-buy for this pack, so it
also ships here as part of the paid bundle.

## Install (60 seconds)

See [INSTALL.md](INSTALL.md). Short version: copy the folders in `skills/` into
`~/.claude/skills/` (Claude Code) or your agent's skills directory, start a new
session, done.
