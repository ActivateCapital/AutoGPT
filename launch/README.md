# Launch posts — DRAFTS, require approval

Nothing in this directory gets posted automatically. Each file is a draft for a channel;
review, edit, and post under your own account — or give the agent explicit per-channel
approval.

Suggested order (all organic, $0):

1. `x-thread.md` — launch day, morning US time
2. `linkedin-post.md` — same day, an hour later
3. `product-hunt.md` — only when payment links are live and you can spend launch day
   responding to comments
4. `communities.md` — staggered over the following week; read each community's
   self-promo rules first, they differ

House rule: every claim in these drafts must stay true (tests passing, refund policy,
prices). If you change the product, change the posts.
